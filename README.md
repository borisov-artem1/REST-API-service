# REST API сервис на Go

Описание вашего REST API сервиса.

## Описание

Этот проект представляет собой REST API сервис, написанный на Go. Он предназначен для обработки запросов, работы с данными и предоставления ответов в формате JSON. Это полностью рабочий REST API сервис готовый к работе с ним.

## Стек технологий

- Go (язык программирования)
    - `go-chi/chi` — актуальный HTTP-роутер
    - `slog` - для работы с логами
    - `gorm` — ORM для работы с базами данных
    - `gin` — фреймворк для разработки веб-приложений
